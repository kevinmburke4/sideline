Setting up the List on X

  1. On x.com, go to Lists, create a new List, and set it to Private so accounts aren't notified.
  2. Add members by searching each handle. The search result shows the profile, which doubles as your check.
  3. Copy the List ID from its URL (the number after /i/lists/). The weekly prompt uses it.
  4. Mute picks content inside X if any account drifts that way: Settings, Privacy and safety, Muted words, then add words like best bet, lock, parlay.
